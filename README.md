# WeatherKit Quantumult X 镜像

这是 `NSRingo/WeatherKit` 的 `v3.2.0-beta1` 固定版本镜像，供个人在 Quantumult X 中使用。

## Quantumult X 订阅地址

```text
https://raw.githubusercontent.com/sbc2fjbdn5-prog/WeatherKit/main/iRingo.WeatherKit.plugin
```

## 镜像内容

- `iRingo.WeatherKit.plugin`：修改后的 QX 插件，运行脚本改为本仓库地址。
- `response.bundle.js`：修改后的运行脚本，NSRingo 托管的数据和图标改为本仓库地址。
- `qweather-china-city-list-grid.json`：运行脚本需要的 QWeather 城市网格数据。
- `ColorfulClouds-*`、`WAQI-*`、`WeatherOL-*`：运行脚本引用的天气数据源图标。
- `upstream-*`：未经修改的原始 Release 插件和运行脚本。
- `SOURCE.md`：上游来源、固定版本和修改记录。
- `SHA256SUMS`：文件完整性校验值。

本镜像不会自动跟随上游更新。上游作者、主页和许可证信息均予以保留。
